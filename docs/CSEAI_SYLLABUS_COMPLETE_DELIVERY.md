## 🎯 The 4 Dynamic Fields

### Field 1: **Regulation Type** ✅
- Type: Select dropdown
- Size: Half-width
- Options: R18, R20, R23, V20
- Required: YES
- Validation: Enum check
- Database Column: `type`

### Field 2: **Syllabus Title** ✅
- Type: Text input
- Size: Full-width
- Placeholder: "e.g., B.Tech CSE-AI - II Year Syllabus"
- Required: YES
- Validation: 5-200 characters, alphanumeric with punctuation
- Database Column: `title`

### Field 3: **Academic Year** ✅
- Type: Select dropdown
- Size: Half-width
- Options: 2023-24, 2024-25, 2025-26, 2026-27
- Required: YES
- Validation: Enum check
- Database Column: `academic_year`

### Field 4: **Syllabus PDF Document** ✅
- Type: File upload
- Size: Full-width
- Accept: .pdf, .doc, .docx
- Required: YES
- Validation: File type, size check, auto cleanup
- Database Column: `fileUrl`
