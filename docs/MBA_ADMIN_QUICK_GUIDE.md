# MBA Admin Dashboard - Quick Reference Guide

## 🎯 Getting Started

### Access Your Dashboard
1. **URL**: `http://localhost:9002/departments/mba/dashboard`
2. **Login**: Use your MBA department credentials
3. **Dashboard**: View all 24 available modules

## ✨ How to Use Each Module

### Adding New Records
1. **Click any module** (e.g., "Faculty")
2. **Click "Add New"** button
3. **Fill the form** - fields are automatically generated
4. **Upload files** if needed (documents, images)
5. **Save** your record

### Editing Existing Records  
1. **Click on any record** in the list
2. **Edit** the pre-filled form
3. **Update files** if needed
4. **Save changes**

### Searching & Filtering
- **Search box**: Type to find records instantly
- **Filters**: Use dropdown filters for specific categories
- **Sort**: Click column headers to sort data

## 📁 File Upload Guidelines

### Supported Formats
- **Documents**: PDF, DOC, DOCX, TXT
- **Images**: JPG, JPEG, PNG, GIF, WebP
- **Spreadsheets**: XLS, XLSX

### File Size Limits
- **Maximum size**: 1MB per file
- **Images**: Automatically resized if needed
- **Documents**: Maintained in original format

### Where Files Are Stored
```
/uploads/mba/
├── faculty/          (Faculty photos and CVs)
├── syllabus/         (Syllabus documents)  
├── handbooks/        (Student handbooks)
├── newsletters/      (Newsletter PDFs)
├── placements/       (Placement reports)
├── achievements/     (Achievement certificates)
└── events/           (Event photos and documents)
```

## 🔄 Auto-Refresh Feature

### How It Works
- **Automatic updates**: Dashboard refreshes every 30 seconds
- **Real-time sync**: See changes made by other users instantly
- **Smart refresh**: Only updates when data actually changes
- **Background operation**: Refreshes happen without interrupting your work

### Visual Indicators
- **Green dot**: System is actively syncing
- **Timestamp**: Shows last update time
- **Status messages**: Confirms when data is saved/updated

## 🛠️ Troubleshooting

### Common Issues & Solutions

#### Forms Not Loading
- **Check internet connection**
- **Refresh the page** (F5)
- **Clear browser cache**
- **Try different browser**

#### File Upload Failures
- **Check file size** (must be under 1MB)
- **Verify file format** (see supported formats above)
- **Ensure stable connection**
- **Try uploading one file at a time**

#### Data Not Saving
- **Fill all required fields** (marked with *)
- **Check for error messages** (red text)
- **Verify form completion** 
- **Try saving again**

#### Search Not Working
- **Check spelling** and try different keywords
- **Use partial words** instead of complete phrases
- **Try filtering** by category first
- **Clear search and try again**
